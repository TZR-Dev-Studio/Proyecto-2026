# SGRSI

Sistema de Gestión de Recursos y Soporte Informático del Proyecto ITI 2026.

El código activo está en `proyecto/`: modelos y controladores en `app/`, configuración en `config/` y pantallas/endpoints en `public/`. Los SQL están en `db/`.

Instalación y conexión: consultar `LEEME_EJECUCION.md`. Resultados y pruebas pendientes: `pruebas/`. Se conserva el uso de PHP, PDO y Fetch trabajado en los ejemplos del curso.

Esta versión ordena el proyecto y mantiene los módulos existentes. La asistencia, las referencias técnicas y las limitaciones de verificación siguen documentadas; la limpieza no sustituye la revisión y las pruebas del equipo.
